  • 학교 수배전반 교체 감리
  • 태양광⁠·ESS 설계와 감리

전력기술 감리업 전문 제161호(에코플랜트 명의). 공사 규모와 발주 조건을 알려 주시면 감리 가능 여부부터 확인해 드립니다.

감리 진행 순서

  1. 설계도서 검토도면, 계산서, 시방서 확인
  2. 자재 확인규격과 시험 성적 확인
  3. 시공 확인결선, 접지, 배관 현장 확인
  4. 준공 서류시험 결과와 준공 도서 확인

도면만 보내 주셔도 시작할 수 있습니다

작업 범위와 일정을 먼저 알려 드립니다.
