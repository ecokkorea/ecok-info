강의 요약

영상의 음성 내용을 글로 정리했습니다. 예제는 모두 가상 발전소입니다.

PVsyst 2강은 발전량 계산의 바탕이 되는 기상 자료를 화면에서 직접 읽습니다. 프로젝트 창 위쪽 두 줄 가운데 Site File은 발전소 위치, Weather data File은 날씨 자료 파일입니다. Weather data File 줄 오른쪽 돋보기를 누르면 기상 표와 그래프 창이 열립니다.

창 위쪽에는 위도 36.91°, 경도 127.04°, 표고 19 m, 시간대 9가 나오고, 출처(Source) 칸에는 PVGIS 5.3 TMY, 곧 위성 자료라고 적혀 있습니다. 왼쪽 Year-to-year variability는 5.1 %로, 해마다 일사가 달라지는 폭입니다. Tables 탭에서 Monthly를 고르고 Show table을 누르면 월별 표가 나옵니다. 맨 아래 연 합계를 읽으면 수평면 전일사 1,412.7 kWh/㎡, 확산일사 541.2 kWh/㎡입니다. Graphs 탭에서는 5월이 가장 높고 12월과 1월이 낮으며, 7월은 장마 때문에 꺾이는 모양이 보입니다.

기상 파일 목록을 펼치면 같은 지역인데도 출처가 다른 파일이 여럿 있습니다. PVGIS 위성 자료, Meteonorm, 기상청 관측 기반 KMA 자료 등입니다. 강의에서는 PVGIS 모양을 기상청 평년값(1991~2020년)에 맞춰 크기를 고친 파일을 골랐습니다. 이 파일은 기상청 실측 시간별 자료가 아니라는 점을 꼭 구분해야 합니다. 파일을 고르면 Check data quality 탭이 열리는데, 맑은 날 시간 어긋남이 0분이면 시간대가 맞다는 뜻입니다.

같은 방법으로 월별 표를 보면 연 합계가 1,306.6 kWh/㎡, 확산 501.1 kWh/㎡입니다. PVGIS의 1,412.7보다 약 7.5 % 적습니다. 그래프 모양은 같고 크기만 작습니다. 보기만 했기 때문에 프로젝트의 기상 파일은 그대로 PVGIS 파일입니다.

결론은 같은 땅도 기상 자료 출처에 따라 연 일사가 7 % 넘게 달라진다는 것입니다. 발전량 보고서에는 어떤 기상 자료를 썼는지 꼭 적고, 은행이나 심사용 검토는 보수적인 국내 관측 기반 자료를 함께 봅니다. 직접 해 보기 과제는 두 파일의 연 합계 차이를 퍼센트로 계산하는 것이고, 정답은 약 7.5 %입니다.

자주 묻는 질문

PVsyst 기상 자료는 어디서 확인하나요?

프로젝트 창 Weather data File 줄 오른쪽 돋보기를 누르면 기상 표와 그래프 창이 열립니다. Tables 탭에서 Monthly, Show table 순서로 월별 표와 연 합계를 읽습니다.

PVGIS와 기상청 자료로 발전량이 얼마나 달라지나요?

강의 예제 땅에서 연 수평면 일사가 PVGIS 1,412.7, 기상청 평년값에 맞춘 파일 1,306.6 kWh/㎡로 약 7.5 % 차이가 났습니다. 보고서에는 쓴 기상 자료를 꼭 적습니다.

Check data quality에서 무엇을 보나요?

맑은 날 시간 어긋남을 봅니다. 0분이면 기상 파일의 시간대가 현장과 맞다는 뜻입니다.

English summary

Lesson 2 reads the weather data behind every PVsyst yield figure. The magnifier next to Weather data File opens the tables and graphs window. The example site sits at 36.91° N, 127.04° E, 19 m above sea level, time zone 9, with PVGIS 5.3 TMY satellite data and a year to year variability of 5.1 %. The monthly table gives 1,412.7 kWh/m² of global horizontal irradiation. A second file, scaled to the Korea Meteorological Administration 1991 to 2020 normals, gives 1,306.6 kWh/m², about 7.5 % less. The same site can differ by more than 7 % depending on the data source, so a yield report should always name its weather file. English subtitles are available on YouTube (CC).
