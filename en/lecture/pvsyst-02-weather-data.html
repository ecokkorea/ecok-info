PVsyst Lesson 2: Weather data, yearly irradiation on the same site differs by more than 7 % by source

Reading the PVsyst weather file tables: PVGIS gives 1,412.7 kWh/m² of global horizontal irradiation and a file scaled to KMA normals gives 1,306.6 kWh/m², about 7.5 % less.

Lesson summary

The narration is in Korean with English subtitles (CC). The text below follows the narration. All examples are virtual plants.

Lesson 2 reads the weather data behind every yield figure directly on screen. Of the two lines at the top of the project window, Site File is the plant location and Weather data File is the meteo data file. The magnifier to the right of the Weather data File line opens a window with weather tables and graphs.

The top of the window shows latitude 36.91°, longitude 127.04°, altitude 19 m and time zone 9, and the Source field says PVGIS 5.3 TMY, which is satellite data. On the left, year to year variability is 5.1 %, the amount irradiation changes from one year to the next. In the Tables tab choose Monthly and press Show table for the monthly table. The yearly total at the bottom is 1,412.7 kWh/m² of global horizontal irradiation with 541.2 diffuse. Show graph in the Graphs tab shows May highest, December and January lowest, and a dip in July from the monsoon rains.

The list of weather files holds several files for the same area with different sources: PVGIS satellite data, Meteonorm and KMA data based on Korea Meteorological Administration observations. The lesson picks a KMA TMY file that keeps the PVGIS hourly shape but is scaled to the KMA normals for 1991 to 2020. It is not measured hourly KMA data, and that distinction matters. In Check data quality, a clear day time shift of 0 minutes means the time zone is correct.

The same monthly table for this file gives a yearly total of 1,306.6 kWh/m² with 501.1 diffuse, about 7.5 % below the 1,412.7 from PVGIS. The graph has the same shape, just smaller. The file was only viewed, so the project still uses the PVGIS weather file.

The conclusion: on the same land, yearly irradiation can differ by more than 7 % depending on the weather data source. Always state which weather data was used in the yield report, and for bank or review purposes also look at the conservative, locally observed data. Try it yourself: read the yearly totals of the two files and calculate the difference in percent. The answer is about 7.5 %.

Frequently asked questions

Where do I check the weather data in PVsyst?

Press the magnifier to the right of the Weather data File line in the project window. In the Tables tab choose Monthly, then Show table, to read the monthly values and the yearly total.

How much does the yield change between PVGIS and KMA based data?

On the example site, yearly global horizontal irradiation was 1,412.7 kWh/m² from PVGIS and 1,306.6 kWh/m² from the file scaled to KMA normals, a difference of about 7.5 %. Always state the weather data used in the report.

What does Check data quality show?

The time shift on clear days. A value of 0 minutes means the time zone of the weather file matches the site.
