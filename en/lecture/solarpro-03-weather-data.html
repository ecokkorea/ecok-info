Solar Pro Lesson 3: Choosing weather data, monthly averages against hourly measured data

Choosing a monthly average weather point or an hourly measured CSV (8,760 hours) in the Solar Pro Location window, and why the same roof showed 0.64 % and 1.21 % shading loss.

Lesson summary

The narration is in Korean with English subtitles (CC). The text below follows the narration. All examples are virtual plants.

Lesson 3 looks at weather data using the Mokpo plant from lesson 2. The same scene gives different results depending on the weather data. Location in the 3D CAD menu opens a window with the weather data set at the top.

The Select Meteorological Database box lists sets such as 1600 Points, MONSOLA-11, METPV-20, METPV-11, TMY3, Additional Points and Import Data. The example uses Additional Points, country Korea, area Mokpo. The point data chosen here are monthly averages. The Area list holds 16 locations in Korea plus Korea Meteorological Administration stations starting with KMA, so changing the name alone switches the calculation to another area's monthly averages.

To use measured data, tick Use Measured Irradiance Data, choose Horizontal as the irradiance type and press Reference. Pick a CSV file with hourly irradiance and temperature, 8,760 hours for one year. Once the file path is in and OK is pressed, the scene is calculated with hourly measured data. The scene itself stays the same, only the results change.

The CSV has seven columns: year, month, day, hour, minute, horizontal irradiance in kW/m² and temperature. If the column order or units differ the calculation goes wrong, so KMA data has to be arranged in this order.

Running the same test roof both ways gave a shading loss of 0.64 % with monthly averages and 1.21 % with hourly data, roughly double. An average day mixes cloudy and clear days, so it underestimates shadows. That is why practical reviews use hourly data, and the report should state whether monthly or hourly data was used. A correction from lesson 2 is included: the row spacing B of 5.936 m is the pitch, and the clear gap is about 3.36 m.

Frequently asked questions

How do I load hourly weather data in Solar Pro?

In the Location window tick Use Measured Irradiance Data, choose Horizontal, then press Reference and pick an hourly CSV with 8,760 rows for one year.

What is the hourly CSV format?

Seven columns in this order: year, month, day, hour, minute, horizontal irradiance in kW/m², temperature.

Does monthly average data change the shading loss?

On the lesson test roof the loss was 0.64 % with monthly averages and 1.21 % with hourly data, about double. Average days mix cloudy and clear weather and make shadows look smaller.
